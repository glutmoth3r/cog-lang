# SDL event canvas

A resizable SDL canvas demonstrating the current `cog-sdl` event enums,
scancode and event-field conversion, mouse coordinate mapping, manual drawing,
and frame pacing.

Run from the repository root:

```sh
cog run examples/libraries/sdl/showcase
```

The app project is `0.1.0` and uses `cog-sdl` `0.13.0`.

Use the arrow keys to move the marker, click to reposition it, and scroll to
change its size. **C** changes its color and **R** resets it.
