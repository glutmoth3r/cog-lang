# Raylib field lab

An interactive 2D playground showing raylib window setup, frame timing,
keyboard and mouse input, resizable rendering, primitives, and text from Cog.

Run from the repository root:

```sh
cog run examples/libraries/raylib/showcase
```

The app project is `0.1.0` and uses `cog-raylib` `0.1.18`.

Use **WASD** or the arrow keys to move, click to jump to a position, and scroll
to change the ring size. **Space** pauses movement, **Q** changes the palette,
and **R** resets the scene.
